# Smith v0.8.1

Smith 0.8.1 replaces the last modal boxes with inline prompts, moves long
foreground shell calls to the background, and makes web research read fewer,
cleaner pages.

## Changes

- Tool approvals and confirmations (`/undo`, `/revert`, `/redo`, `/review`,
  trust prompts, child follow-up and resume, account rotation) no longer open
  a centered bordered box. They render at the bottom of the screen, in place
  of the composer while open, with the same numbered list as the
  questionnaire: `❯ 1. Yes`, `2. Yes, don't ask again…`, `3. No (esc)`.
  `↑↓` move the highlight, `Enter` answers, and the digits and `y`/`a`/`n`/`Esc`
  answer directly. `Shift+↑↓` scrolls long evidence; `PgUp`/`PgDn` still
  scroll the transcript. Your draft returns when the prompt closes.
- An approval's highlight starts on `Yes`; keys typed just before the prompt
  appeared are still ignored, so a stray `Enter` cannot grant anything. A
  confirmation's highlight starts on cancel, so `Enter` alone never applies an
  undo or a trust grant.
- A foreground shell call still running after 5 minutes moves to a session
  background task, keeping its output so far and the rest of its
  `timeout_ms`. A command that leaves a backgrounded process holding the
  tool's output (`nohup server > log 2>&1 &` inside `cd x && …`) no longer
  holds the turn open.
- `web_fetch` drops page chrome, image URLs, and empty links from the
  Markdown it returns, and a fetched page or a child's report stays inline up
  to `limits.tool_output_limit_bytes` instead of being paged back 2 KiB at a
  time. Pages are stored once.
- Web research starts from search results and fetches the page that settles a
  claim, within a source budget (about ten pages unless the task sets one).
  Read-only research children keep `web_fetch`, search, and their own
  `artifact.read`/`artifact.list`. Gemini grounding citations resolve to the
  pages they cite, and each source is linked once per message.
- `artifact.read` returns a text page as text when a page edge splits a
  multi-byte character, instead of an array of byte values.
- xAI login saves approved credentials without asking a second time.

## Compatibility

- Session and event formats are unchanged from 0.8.0 (stream-json runtime
  events are schema 17). 0.8.0 sessions resume in 0.8.1.
- No user credentials or personal configuration are included in the release.
- Agent Runtime is pinned to `9f3ff2ffcb403693f1a291e28aae16e49fd6ffbb`
  (Agent Runtime v0.12.0, on `main`).
