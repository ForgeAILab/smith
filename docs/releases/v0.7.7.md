# Smith v0.7.7

Smith 0.7.7 clarifies prompt-cache status and fixes vision tool schemas for
providers that reject top-level schema composition.

## Changes

- Built-in task guides help the agent explain setup, models and thinking,
  vision, profiles, sessions, extensions, headless use, and troubleshooting.
- Module setup hints explain missing configuration. With a text-only main
  model and no vision selection, Smith names available image-capable
  profiles. Explicit `vision = false` suppresses that hint;
  `smith config explain vision` distinguishes unset and disabled values.

## Fixes

- **Cache status is explicit before the first turn completes.** The footer
  shows `CH –` while no completed root-turn summary exists. After completion,
  it shows a reported percentage, including `CH 0%`, or `CH ?`. When space
  permits, an unknown percentage explains whether the provider omitted cache
  reads or prompt-input totals.
- **Vision tool schemas work with stricter providers.** `view_image` no
  longer uses top-level `oneOf` in its input schema. Its description and
  preparation checks still require exactly one image reference or path.

## Maintenance

- Saved terminal fixtures omit unused blank space above the composer while
  retaining the 512-row rendering backend, report contents, and footer.
- The default agent wait remains five minutes; individual calls can request
  a shorter `timeout_ms`. No new paired benchmark establishes token savings
  from lazy loading or output offloading.
