# Smith v0.7.10

Smith 0.7.10 fixes access to external reference images, adds more ways to
respond to agent questions, and removes the checkpoint size cap that could
stop image-heavy sessions.

## Changes

- Filesystem tools can request permission for paths outside the project.
  `--yolo` and `--approval allow-all` grant that permission automatically.
  Relative paths still resolve from the project, and profile tool
  restrictions continue to apply.
- External image reads return validated image content to image-capable
  models. The vision fallback accepts authorized external image paths too.
- Agent questions always accept a custom answer. Choose **Other · Type an
  answer**, or **Chat about this question** to send a message before deciding.
  Escape returns from the discussion draft without losing staged answers.
- Protected checkpoints no longer have a fixed 32 MiB payload or envelope
  limit. Large image histories can save and resume through the existing
  encrypted checkpoint format.
- Profile, child-agent, and advisor pickers display installed CLI model IDs
  without repeating the provider prefix.

## Compatibility

- Existing checkpoint files remain compatible. Authentication, schema,
  checkpoint transition, and owner-only storage checks remain enforced.
- Agent Runtime remains pinned to
  `a0a245989c169c68294194be805440c8d6a4cc41` on the v0.7.0 line.
