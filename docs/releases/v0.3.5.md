# Smith v0.3.5

Smith 0.3.5 finishes three pieces of terminal polish left over from 0.3.1.

## Changes

- **Agent details read as words.** `/agents` and the agent inspector name a
  child's workspace the way its spawn row does (`read only`, `shared`, …)
  and say `exact resume available` or `no exact checkpoint`. Before, they
  printed `ReadOnlyView` and `resumable false`. Long rows wrap at word
  boundaries with an indent instead of breaking mid-word.
- **Setup previews scroll.** In first-run setup, a review or configuration
  merge preview taller than the window scrolls with the arrow and page keys
  to its last line, and the footer keys stay visible. Before, the end of the
  preview was cut off.
- **Streaming tables hold still.** While an answer is still sending a table,
  Smith shows the table's header and a dim `receiving table…` line, then
  draws the whole table aligned once it is complete. Before, rows already on
  screen shifted each time a wider cell arrived.

## For developers

`/help` and the `?` shortcuts panel are generated from a typed key table,
and a test runs every listed key through the real key handling, so the
listed keys cannot drift from what the keys do. The interactive loop is
split into one handler per event source and per action.

Existing profiles, configuration, and sessions remain compatible.
