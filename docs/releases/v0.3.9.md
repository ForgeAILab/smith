# Smith v0.3.9

Smith 0.3.9 is an internal maintenance release. Nothing you see or configure
changes.

## Under the hood

- **No Rust source file is over 1,500 lines.** The 30 files over that size
  were split into child modules of at most 1,000 lines each. Code only moved:
  module paths, visibility, fixtures, and test binaries are unchanged.
- **A test keeps it that way.** `every_rust_file_is_within_the_line_budget`
  fails when any `.rs` file under `crates/` passes 1,500 lines and names the
  file.
- **Spec housekeeping.** Nine earlier changes that had already shipped are
  archived into the specs, among them installed coding agents, bounded tool
  output, MCP servers, and the per-profile delegation switch. The installed
  coding agents spec now describes selection by model id, as shipped. Work a
  change never did, such as the Harbor benchmark run, is recorded as not done
  rather than claimed.

Agent Runtime stays on `fc92efb`, the same version 0.3.8 used.
