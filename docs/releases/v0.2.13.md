# Smith v0.2.13

Smith 0.2.13 fixes a headless shutdown hang after a failed parent turn.

When a child completed near the same time that the parent failed, Smith could
keep waiting for an automatic child-completion continuation that Runtime would
never admit. The process then emitted neither its final structured result nor
its non-success exit status.

Headless runs now wait for required goal and child follow-up work only after a
normally completed parent turn. Failed, cancelled, limit-reached, and
interaction-required turns proceed directly through ordinary cleanup and emit
their terminal result. Protected child outcomes remain available through the
existing persistence and resume path.

No configuration or session migration is required.
