# Smith v0.7.9

Smith 0.7.9 adds direct skill commands, makes the session's jump-to-bottom
shortcut easier to find, and improves recovery from provider failures.

## Security updates

- Wasmtime is updated to `36.0.19`, fixing the Cranelift sandbox-escape
  advisories [RUSTSEC-2026-0379](https://rustsec.org/advisories/RUSTSEC-2026-0379)
  and [RUSTSEC-2026-0380](https://rustsec.org/advisories/RUSTSEC-2026-0380).
- `rustls-webpki` is updated to `0.103.16`, fixing certificate verification
  for distrusted intermediates
  ([RUSTSEC-2026-0382](https://rustsec.org/advisories/RUSTSEC-2026-0382)).
- The `v0.7.8` candidate was cancelled before publication; this release
  includes its changes and the security patches.

## Changes

- **Activate a skill by name.** Detected skills appear in slash completion as
  `/<skill-name>`. Invoke one alone to activate it locally for your next
  prompt, or add a task to activate and run it immediately. `/skills use
  <name> [task]` handles command-name collisions. Activation enforces trust,
  current file contents, capability permissions, and instruction budgets.
  These commands use provider-backed turns; installed CLI backends use their
  existing skill MCP bridge.
- **Jump to the bottom without changing your draft.** `Ctrl+L` and
  `Ctrl+End` jump to the newest output and resume following, including while
  slash completion is open. The footer shows `Ctrl+L bottom` when scrolled
  up, and `/help` and the `?` shortcuts panel list both keys.
- **Choose a Harbor model serving.** The benchmark bridge supports pinned
  `luna-max` and `glm-5.3` servings, serving-specific credential handling,
  canary checks, and descriptive comparisons across servings.

## Fixes

- Retryable provider failures use exponential backoff with jitter and honor
  longer server retry hints. Interrupting work also cancels the wait.
- The pinned Agent Runtime now includes bounded recovery from malformed
  tool arguments.
- OpenAI-compatible endpoints receive explicit reasoning selections even
  when model metadata is missing or its advertised effort list is incomplete.
  The endpoint validates the selected value. Private endpoints use
  `reasoning_effort` unless another request format is configured.

## Upgrade notes

- The default `limits.max_retries` increases from `2` to `5`, allowing up to
  six provider attempts. Set it to `2` to retain the previous allowance, or
  `0` to disable retries for transient provider failures.
- Agent Runtime remains on the v0.7.0 line, pinned to revision
  `a0a245989c169c68294194be805440c8d6a4cc41`.
