# Smith v0.2.16

Smith 0.2.16 fixes a startup failure introduced in 0.2.15.

A configuration that gives a model flat `context_tokens` or
`max_input_tokens` no longer fails when Smith's built-in catalog also names a
default context window for that model. 0.2.15 added such a record for
`chatgpt/gpt-6.1-sol`, so a `[models."chatgpt/gpt-6.1-sol"]` block with flat
limits stopped every session with `window 272k is pinned by flat model limit`,
including sessions whose selected profile used a different model but had that
profile enabled for child agents.

The flat limits now apply, as they did in 0.2.14. Selecting a named window
for a model pinned by a flat limit still fails with the error that names the
flat key.

Existing profiles and configuration remain compatible.
