# Smith v0.3.7

Smith 0.3.7 redraws the screens around a session — setup, `--resume`,
sign-in, and `/connect` — as plain lists in the style of Claude Code, and
fixes a session price that billed every token at the last model's rates.

## Fixes

- **A session that switched model is priced correctly.** After `/model`,
  the exit report and `/status` priced every token at the newest model's
  rates and still called the figure exact. Each model's tokens are now
  priced at its own rates, and the line names every model with its share:
  `$0.034 exact · zai/glm-5.3 $0.022 · google/gemini-3.8-flash $0.012`.
  Child agents are priced at their own model's rates, as are cache
  keepalives. Resuming an older session that used several models prints no
  figure for that usage rather than a wrong one. A session that used one
  model prints exactly what it did before. The usage log records each
  model's counters.
- **Keys typed during a rebuild are kept.** Text typed right after choosing
  a model, profile, or connection was lost while the session rebuilt; it now
  reaches the composer.

## Screens around the session

- **No more boxes.** Setup, `smith --resume`, ChatGPT and xAI sign-in, and
  account choices draw from the top-left: a title line, the choices, and one
  footer in the session's words (`↑↓ choose · enter confirm · esc back`).
  Short choice lists are numbered; press the digit to choose.
- **Esc goes back one step.** In setup and `/connect`, Esc returns to the
  previous step with your choices kept, and cancels only on the first step;
  Ctrl+C cancels the whole flow. Choosing ChatGPT in setup and pressing Esc
  returns to setup instead of quitting. Cancelling setup says
  `Setup cancelled · nothing was written`.
- **Setup says what it does.** It opens with a welcome and says nothing is
  sent until it finishes. The review lists one fact per line with compact
  sizes (`1M context`, `131k output`) and `~/.smith/config.toml`. Credential
  choices name the real keychain entry, and no step mentions a command you
  cannot type there.
- **`/connect` stays in the session.** Its steps appear above the composer
  with the transcript in place, and the result appears as a notice. Before,
  the session disappeared behind a `Smith setup` box and messages printed
  behind it were lost. `/disconnect` works the same way.
- **xAI sign-in has a screen.** It shows the code, the link, and a waiting
  line, and Esc cancels it.
- **Resume lists sessions by what you asked.** Rows read
  `What does lib.rs define?  2 min ago · 1 turn · zai/glm-5.3`, with the
  session id under the selected row. Every session can be scrolled to.
  Sessions where nothing was typed are no longer offered, and quitting one
  no longer prints a resume command. `smith sessions list` piped to another
  program is unchanged.
- **`/model` opens on the current model**, and its detail line uses compact
  sizes (`1M context · 131k output ceiling · request 32.7k automatic`).

## For developers

Every screen shown outside a session — setup, `--resume`, sign-in, account
choice — runs through one terminal loop, and every chooser through one list
component; the five separate loops are gone. A screen repaints whole when a
flow moves to a new step. The standalone screens have golden fixtures at
44x16 and 100x32.

Existing profiles, configuration, and sessions remain compatible. The usage
log moves to schema version 5; readers accept versions 1–5.
