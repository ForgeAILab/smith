# Smith v0.8.2

Smith 0.8.2 hardens long single-turn autonomous runs with intra-turn
compaction, mid-turn budget notices, long-session WASM extension stability,
and child-process credential scrubbing.

## Changes

- Long single-turn runs (`smith -p` and extended TUI tool loops) no longer
  fail with `budget_exceeded` when accumulated tool exchanges fill the input
  window. Agent Runtime v0.12.1 keeps the initial prompt, mid-turn user
  steers, and the newest two completed exchanges required while making older
  completed intra-turn exchanges eligible for structural compaction (stripping
  stale unsigned reasoning, bounding optional paired tool results and history
  text, and atomically evicting the oldest optional group only as a
  hard-budget rescue) while keeping prefix caches byte-stable under budget.
- `budget-notice` now observes live provider usage before every mid-turn
  request via `TurnCommitHook::before_provider`, remains active even when
  semantic summaries are disabled, scales its warning threshold for tight
  context windows, and measures against the planner's enforceable
  `ContextBudget::input_budget`.
- Sandboxed WASM modules remain healthy on long sessions: `UsageSource::SemanticSummary`
  projects cleanly without breaking the v0.1/v0.2 WIT ABI, `ToolOutputProcessor`
  caps usage views to the newest 256 records outside health accounting so
  oversized host inputs never falsely disable a module, and
  `ContextContributor` receives the newest bounded history suffix past 256
  messages.
- Resolved `CredentialRef::Env` provider, fallback, web-search, checkpoint,
  and MCP environment variables are scrubbed with safe `Command::env_remove`
  from foreground `shell`, background `shell`, and stdio MCP subprocesses
  (unless explicitly configured in an MCP server's own `env` table), keeping
  `PATH`/venv inheritance and `WCOREDUMP` behavior intact without leaking API
  keys into child processes or core dumps.
- Includes `harness-feedback` (`harness_feedback` tool and local report review)
  and the `context-probe` Harbor benchmark profile with cache-weighted input
  and hit-rate metrics.

## Compatibility

- Session and event formats are unchanged from 0.8.1 (stream-json runtime
  events are schema 17). 0.8.0 and 0.8.1 sessions resume in 0.8.2.
- No user credentials or personal configuration are included in the release.
- Agent Runtime is pinned to `730f1ef759b0b2ce18021ceaa38a8fd8f1eb9a59`
  (Agent Runtime v0.12.1, on `main`).
