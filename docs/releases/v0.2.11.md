# Smith v0.2.11

Smith 0.2.11 adds selectable context windows and image generation for supported
OpenAI providers. It also splits large Smith and Agent Runtime modules by
responsibility while preserving their public entry points.

## Selectable context windows

Models can declare named context windows with their own enforceable input
limits. Choose one in a profile, with `--context-window`, or during an idle
session with `/context`. The model picker and status display show the active
window. Smith validates a selection before contacting the provider and
compacts saved history when a resumed session moves to a smaller window.

Reviewed ChatGPT models expose their supported 272k and 872k choices; the
exact OpenAI Platform endpoint exposes its reviewed 272k and 1m choices.
Custom model windows can be configured under
`[models."provider/model".context_windows.<name>]`.

## Image generation

The `generate_image` tool can create a PNG from a prompt or edit up to five
reference images. References may be explicit files or recent conversation
images. The tool is available with ChatGPT and the official OpenAI Platform
provider, subject to the usual network approval policy. It saves files under
`~/.smith/generated_images/<session>/<call>.png`; the TUI reports the path
and dimensions.

Configure availability, model, quality, and size under
`[tools.image_generation]`. Generated image data remains in the saved session
in this version, so sessions with many images can grow substantially.

## Internal organization

The runtime factory, cache controller, headless runner, and TUI app state now
have smaller modules with clearer ownership. Agent Runtime's cache, session,
and provider identity code is split along the same lines. Smith pins the
runtime revision that also fixes image tool output accounting, so generated
images reach the model instead of being truncated based on base64 length.

## Upgrading

No configuration migration is required. Existing models keep their current
context limits unless named windows are configured or reviewed for their
provider. Image generation is only registered for supported providers and is
unavailable in plan mode.
