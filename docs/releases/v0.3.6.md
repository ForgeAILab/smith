# Smith v0.3.6

Smith 0.3.6 fixes what a hands-on session with 0.3.5 turned up: a slash
command that could not be cleared, undo patches that listed whole files, and
several screens that showed internal values.

## Fixes

- **Editing a slash command works.** In a draft that starts with `/`,
  Ctrl+U, Ctrl+W, Ctrl+A, Ctrl+E, Ctrl+K, Alt+B, Alt+F, the arrow keys,
  Home, End, and Delete now edit the draft. Before, they did nothing, so a
  refused command could not be cleared and the next command was added to
  it (`/agents/agent`).
- **Undo, redo, and revert show what changed.** Their patches are line
  diffs in hunks with three lines of context, instead of every line of the
  file removed and added back.
- **Paths are relative.** Approvals and recovery patches name files relative
  to the project (`src/lib.rs`), once, at the top of the box.
- **Child-agent approval reads plainly.** Starting a child agent asks
  `Start a child agent` with the task, the child's tools and workspace, and
  any limit that is set. Before, it listed raw fields such as
  `max_turns: 4294967295` and `Warning: host-defined authority`.
- **Agent details.** `/agent` output is headed `/agent`; the inspector shows
  each fact once and renders the child's answer as Markdown; counts read
  `1 turn`; the agents panel row no longer shows the child's session id; a
  spawn's result reads `child-1 started · its result arrives when it
  completes` instead of JSON.
- **No internal notices.** The `activation epoch …` line no longer appears
  in the transcript; it is shown with Ctrl+O and in `/diagnostics`.
- **Wording.** `1 unchanged line`; the `a` choice reads `Yes, and don't ask
  again for … this session`; undo after resume explains that undo is not
  available for turns from before the resume; `/model` writes every context
  size compactly (`1M`, `272k`); confirmation boxes have the same inner
  padding as approvals.

## For developers

A headless run's result accounting is computed by a value that can be
driven without a host, and each picker's entries are built by its own
function.

Existing profiles, configuration, and sessions remain compatible: sessions
written by 0.3.3 and 0.3.4 were resumed with 0.3.6 for this release.
