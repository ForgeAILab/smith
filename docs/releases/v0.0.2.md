# Smith v0.0.2

Smith 0.0.2 fixes Linux release portability.

The canonical x86_64 and ARM64 Linux archives are now fully static musl
binaries. They run without a host glibc dependency on Debian 12, Alpine, Ubuntu,
and newer mainstream Linux distributions. The npm and curl installers select
these portable archives on every Linux host.

Native GNU alternatives remain available with explicit
`smith-<arch>-linux-gnu.tar.gz` names. They are built on Ubuntu 22.04 rather
than a moving `ubuntu-latest` baseline.

The portable binaries retain Smith's vendored Linux Secret Service/keyring
support. Headless users can still explicitly choose an environment reference
or owner-only plaintext `~/.smith/config.toml` during guided setup.

## v0.0.1 Linux limitation

The `v0.0.1` GNU/Linux archives require glibc 2.38/2.39 and do not start on
Debian 12 (glibc 2.36). Users who must remain on `v0.0.1` can build that exact
tag locally:

```sh
sudo apt-get update
sudo apt-get install --yes --no-install-recommends libdbus-1-dev pkg-config
cargo install \
  --git https://github.com/ForgeAILab/smith.git \
  --tag v0.0.1 \
  --locked \
  --root "$HOME/.local" \
  --force \
  smith-cli
```

Upgrading to the canonical `v0.0.2` Linux archive is recommended.
