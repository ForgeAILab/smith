# Smith v0.3.10

Smith 0.3.10 adds an `/advisor` command and fixes four things found while
setting up and using a custom provider.

## New

- **`/advisor` switches the advisor during a session.** `/advisor` opens a
  picker; `/advisor off`, `on`, `default`, `<profile>`, or
  `<provider>/<model>` select directly. The choice applies at the next idle
  turn, keeps the session and its history, and does not write `config.toml`.
  It resets to configuration on restart, `/new`, and `/resume`. `/status`
  has a new `advisor` row showing the effective advisor and whether
  configuration or the session chose it.

## Fixed

- **Guided setup says what it did.** `smith setup` used to exit without a
  word, and a first run dropped you on the start page with no confirmation.
  Both now show a line such as
  `Setup complete · added acme/model as the default · saved to ~/.smith/config.toml`.
- **Host and network prompts reach the shell.** The shell tool was only found
  by coding words, so "scan this server" activated nothing and the model
  reported that it had no terminal. It now also matches words such as `scan`,
  `port`, `server`, `network`, `curl`, `dns`, and `terminal`.
- **A proxy block is no longer reported as a bad key.** A 403 block page from
  an edge proxy in front of the provider (HTML, or Cloudflare's
  `cf-mitigated` header) read as "provider authentication rejected". It is
  now reported as a request the proxy blocked before it reached the provider.
- **The capability-search row no longer flashes.** The row was drawn while
  the search ran and removed when it succeeded a few frames later. It is now
  hidden while running; a failed or denied search still shows.

Agent Runtime stays on `fc92efb`, the same version 0.3.9 used.
