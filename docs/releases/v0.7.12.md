# Smith v0.7.12

Smith 0.7.12 makes delegated agents readable as full conversations and gives
the main agent a way to inspect their work without repeatedly checking status.

## Changes

- `/agent <id>` shows the child's delegated task, assistant messages,
  permitted reasoning, tool calls and results, and final answer using the
  main conversation's renderer. Older retained work stays accessible.
- The main agent can read a child's committed conversation with `agent`
  action `transcript`. Reads use stable pages; large entries have readable,
  parent-owned artifact references.
- Late subscriptions recover earlier messages and pending output without
  duplicate rows. Retained conversations remain readable after restarting
  the parent without resuming the child.
- Hosted search and installed-agent tool activity survive recovery in their
  original order, including commentary before and after tool calls.
- The child view and delegated-work panel show observed activity and the age
  of the last progress event. They distinguish provider waiting from tool
  execution and keep the correct activity when tool details arrive late.
- Delegation guidance tells the main agent to continue independent work or
  park for automatic result delivery, inspect transcripts when needed, and
  use `agent stop` for children rather than shell-task controls.

## Compatibility

- Existing child IDs, completion delivery, and explicit resume/stop behavior
  remain compatible. Transcript reads do not execute child work or consume
  pending completion delivery.
- Older sessions identify activity that was not retained by their format.
  Credential redaction and protected-reasoning visibility remain enforced.
- Child lifetime limits are unchanged. This release does not claim to resolve
  a provider request that has stalled.
- Agent Runtime remains on the v0.7.0 line, pinned to
  `bba8996c213f2f65287d84befc1c7dc6ced3241a`.
