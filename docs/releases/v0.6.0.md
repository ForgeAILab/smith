# Smith v0.6.0

Smith 0.6.0 lets models see image files and lets you attach images to a
headless prompt. Installed coding agents now run their own tools without
asking. Agent Runtime moves from a feature branch to a tagged release.

## Upgrade notes

- **Sessions upgrade one way.** A session that 0.6.0 has written cannot be
  resumed by Smith 0.5.0 or older, which reports "canonical turn manifests
  and terminal checkpoint are from different boundaries". Sessions written by
  0.5.0 resume normally in 0.6.0. Keep a 0.5.0 binary only for sessions it
  has not seen since the upgrade.
- **Installed coding agents run their own tools by default.** On a `cli/...`
  profile, `[harness.<kind>] allow_own_tools` now defaults to on, and on
  means the CLI's no-prompt mode:
  - Claude Code runs with `--permission-mode bypassPermissions`, replacing
    `acceptEdits`.
  - Codex runs with `--dangerously-bypass-approvals-and-sandbox`, replacing
    `--sandbox workspace-write`.
  Previously, a prompt the CLI raised in a non-interactive turn was an
  automatic denial, so WebFetch, WebSearch and most shell commands always
  failed. To keep the old behavior, set `allow_own_tools = false` in your own
  config. For Claude Code you can narrow instead, for example
  `args = ["--permission-mode", "acceptEdits"]` or
  `args = ["--disallowedTools", "WebFetch"]`. Project config still cannot
  change either setting.
- **For headless consumers:** runtime events in stream-json now carry event
  schema 16 (was 15). The result envelope is unchanged at schema 3.

## New

- **Models can see image files.** `read` returns a PNG, JPEG, GIF or WebP file
  as the image itself, followed by a line such as
  `photo.jpg · 6016×6016 → 1600×1600 JPEG · 194 KiB`.
  - Images are fitted to the active provider's limits. They are downscaled
    and, when the provider does not accept the format, converted. An image
    that already fits is sent unchanged.
  - Other binary files are still refused.
  - A text-only model still receives a placeholder that `view_image` can
    inspect.
- **Attach images.** `smith -p "…" --image <PATH>` (repeatable) adds images to
  a headless prompt. In the TUI, `@FILE` on an image attaches it like a
  pasted image. `--image` with a `cli/...` profile exits with an error
  rather than dropping the image.

## Changed

- **A read-only root profile narrows the installed agent too.** A root
  profile with `plan` or `review` posture now runs the CLI with its own tools
  off, as read-only child agents already did.
- **Agent Runtime moves to v0.4.0**, a tagged release on its `main` branch,
  instead of a feature-branch commit. It adds an opt-in flat semantic
  summary, which Smith uses; Smith does not enable lossless context memory.
  0.5.0 used `b037801`.

## Fixed

- **Installed-agent turns keep `web_search`.** A `cli/...` profile whose
  named provider has hosted search (Gemini, Anthropic, OpenAI, xAI) lost
  search entirely: `auto` chose hosted search, which the CLI never sees. Such
  turns now get Smith's backend search.
