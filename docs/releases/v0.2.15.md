# Smith v0.2.15

Smith 0.2.15 adds GPT-6.1 Sol to the model picker for the experimental direct
ChatGPT provider and the installed Codex CLI harness.

Select `chatgpt/gpt-6.1-sol` for direct ChatGPT access or
`cli/codex/gpt-6.1-sol` for Codex. The direct ChatGPT binding offers the
default `272k` context window and the extended `872k` window, with Smith's
existing conservative 16,384-token output cap.

The embedded Models.dev catalog is refreshed so offline first runs also
include GPT-6.1 Sol metadata, pricing, and its supported reasoning efforts
for compatible endpoint-bound providers. OpenAI Platform offers the reviewed
`1m` default and `272k` context windows for this model.

Existing model selections and profiles remain compatible.
