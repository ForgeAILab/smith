# Smith v0.3.3

Smith 0.3.3 lets a session continue on another provider, and makes long
conversations fast to draw.

## Switching provider keeps the session working

A session that ran on Gemini, Anthropic, or xAI could fail as soon as it
continued on another provider: Gemini → Z.AI, Gemini → xAI, xAI → Gemini, and
Anthropic → Gemini were rejected, because each provider received the previous
provider's signed reasoning as if it were its own. Smith now records which
provider and model produced each piece of reasoning and leaves another
provider's reasoning out of the request; switching back sends it again. Tool
calls from another provider's earlier turns are accepted by Gemini.

Same-model sessions send exactly the requests they sent before, so their
prompt cache is unaffected.

## Faster transcript

The transcript keeps each block's rendered rows and redraws only blocks that
changed, drawing just the rows on screen. With 5,000 blocks and an answer
streaming, a frame now takes about 0.17 ms instead of 24 ms. Long
transcripts scroll all the way to their first line.

## Fixes

- Shutting a session down no longer drops goal and plan updates that were
  still queued for the resume record.

Existing profiles, configuration, and sessions remain compatible.
