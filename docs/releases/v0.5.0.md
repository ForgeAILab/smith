# Smith v0.5.0

Smith 0.5.0 gives Claude Code and Codex turns Smith's agents, advisor, MCP
servers, plugin tools and skills. It adds web fetch and search, delivers
images from MCP tools to the model, and lets a text-only model ask a vision
model about an image. Quitting is now immediate and always finishes within
10 seconds.

## Changed

- **`/quit` exits at once.** It no longer asks for confirmation, even during
  a turn, with a prompt open, or while child agents or background tasks run.
  Pending approvals are cancelled, never granted. The exit summary adds a
  `stopped:` line naming the work that was cut off; resume the session to
  continue it.
- **Every exit finishes within 10 seconds.** The clock starts at `/quit`, at
  the end of a headless run, or at the first SIGINT, SIGTERM or SIGHUP.
  Whatever has not stopped when it runs out is killed and the exit reports
  the deadline. A headless run still writes its result, and the terminal is
  always restored.
- **The TUI handles SIGTERM and SIGHUP like `/quit`.** It used to die with
  the terminal left in raw mode. It exits with status 0.
- **Read-only postures keep web and vision tools.** `[agent]
  read_only_network_modules` defaults to `["web", "vision"]`, so a plan
  posture can use `web_fetch`, backend search and `view_image`, still subject
  to approval. Set it to `[]` to keep strictly read-only tools.
- **For headless consumers:** results gain an optional `diagnostics` array
  (additive; the result schema stays 3), which also names MCP servers that
  need trust. SIGINT, SIGTERM and SIGHUP cancel the turn and report the
  existing `cancelled` result.

## New

- **Claude Code and Codex turns get Smith's capabilities.** A
  `cli/claude-code` or `cli/codex` turn sees one MCP server named `smith`
  offering the agent tool, the advisor, Smith-declared MCP servers, plugin
  and module tools, and skills. The CLI keeps its own file and shell tools.
  Bridged calls pass through Smith's approvals, workspace rules,
  cancellation, deadlines and output bounds, and are recorded in the session
  history. The CLI process ends whenever Smith exits, including on SIGKILL.
- **Web fetch and search.** A new `web` module adds `web_fetch` (a bounded
  GET with HTML converted to Markdown, private and metadata addresses
  refused on every redirect, host-scoped approval) and `web_search`. In the
  default `auto` mode, OpenAI, ChatGPT, xAI, Anthropic and Gemini use the
  provider's own search, with citations as links; other providers use
  DuckDuckGo with no key, or Brave, Tavily or SearXNG set in
  `[tools.web_search]`. An account that rejects hosted search falls back to
  the backend. Hosted search costs extra at the provider (Anthropic charges
  $10 per 1,000 searches); `mode = "backend"` avoids it.
- **Images from MCP tools reach the model.** Screenshots and other MCP image
  results arrive as images. In a long session older images become
  placeholders to bound request size, and a text-only model gets
  placeholders only.
- **A vision model for text-only agents.** The `vision` setting takes a
  profile, `"<provider>/<model>"` or `false`, and picks the model a
  text-only agent asks about an image through `view_image`. It reads images
  outside the workspace, such as generated ones, after approval.

## Fixed

- **`generate_image` works again.** Smith's authority check denied its write
  to the generated-images directory, so every call failed, even under
  allow-all. That one write now goes to approval; other host writes stay
  denied.
- **A tool call with invalid arguments no longer fails the turn.** It
  returns to the model as an error the model can correct.
- **ChatGPT models see images.** They were treated as text-only, and
  tool-result images were sent to them as text.
- **A busy stdio MCP server no longer outlives Smith,** even when Smith is
  SIGKILLed. Each server runs under a small watchdog process that stops it
  when Smith exits.
- Usage and the exit summary name a Claude Code or Codex model without the
  profile's provider (`cli/claude-code/haiku`).
- An interactive session names each untrusted MCP server once when it opens
  or resumes, with the `/mcp trust <name>` command to run.
- The Agent Runtime conformance test that failed intermittently on macOS CI
  (#4) now runs on a simulated clock.

Agent Runtime moves to `b037801` for external tool dispatch, image content,
hosted web search and the shutdown test fix; 0.4.0 used `d2752c1`.
