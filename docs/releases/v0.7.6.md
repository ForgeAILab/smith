# Smith v0.7.6

Smith 0.7.6 reworks how you answer an agent's questions: the questionnaire
now sits above the composer as a list, the same way `/model` does, and
answers with one keypress.

## Upgrade notes

- **Session formats are unchanged.** Sessions written by 0.7.5 and earlier
  resume in 0.7.6. Runtime events in stream-json stay at event schema 16, and
  the result envelope stays at schema 3.
- **The runtime pin is unchanged** (Agent Runtime v0.7.0).

## Changes

- **Questions are answered inline.** A question used to open a centered
  box in which Enter only marked an answer, and Tab had to reach `[Next]`
  or `[Submit]` before anything was sent. Questions now draw above the
  composer. ↑↓ moves, and Enter or a choice's number picks it and moves on.
  A form with one question is submitted as soon as it is answered.
- **Typing your own answer works.** "Type something." is the list's last
  row, and typing anywhere in the list starts it. Before, an answer to a
  question that also had choices could not contain a space or a digit,
  Enter replaced typed text with the highlighted choice, and deleting the
  text could clear a choice already picked. Pasting into the row works.
- **Forms with several questions** show a tab bar (`□ Scope  □ Tests
  ✓ Submit`), which tab or ←→ switches. After the last question a review
  tab lists every answer and offers "Submit answers" or "Decline to
  answer". Submitting with a question unanswered returns to it.
- **A question ignores keys for half a second after it appears**, as
  approvals already did, so a keystroke meant for the composer cannot
  answer it. Esc still cancels.

## Known limits

- A question still takes one answer. Picking several choices for one
  question needs a change to Agent Runtime's interaction protocol.
