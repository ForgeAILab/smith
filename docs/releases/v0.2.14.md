# Smith v0.2.14

Smith 0.2.14 adds current GPT-6 and Claude catalog coverage.

GPT-6 Sol and GPT-6 Luna now appear beside GPT-6 Astra for both Smith's
experimental direct ChatGPT provider and the installed Codex CLI harness. The
direct ChatGPT bindings carry the reviewed 272k default and 872k extended
context windows with Smith's existing conservative 16k output cap.

The embedded Models.dev snapshot is refreshed so an offline first run knows
the current GPT-6 variants and Claude Opus 5.5. Claude Code selections remain
the vendor's rolling aliases (`opus`, `sonnet`, `fable`, and `haiku`), allowing
an updated Claude executable to resolve the current dated release without a
Smith catalog change.

Existing profiles and configuration remain compatible.
