# Smith v0.7.13

Smith 0.7.13 enables automatic semantic compaction for persisted conversations
and adds `/compact` to summarize older history at an idle boundary.

## Changes

- Persisted sessions install the semantic summary coordinator automatically.
  The standard policy considers summaries after four completed turns and
  triggers at 85% of the available budget after the stable prefix, retaining
  the two most recent turns. Structural compaction remains active.
- `/compact` requests compaction immediately. `/compact <instructions>` adds
  instructions for that attempt. Failed summary work preserves original
  history and the previous committed summary.
- `context.compaction.model` selects a summary profile or API provider/model.
  `context.compaction.instructions` adds default summary instructions.
  `/compact model` and `/compact instructions` validate and save these
  defaults while preserving unrelated user settings and comments.
- `/compact idle 15m` saves the active provider/model's idle cutoff.
  Model-specific values use `[models."provider/model".cache]` and follow
  normal configuration precedence. These cutoffs control Smith's idle
  policy; they do not set or guarantee a provider's cache lifetime.
- Summary work uses its own model limits and usage attribution. Saved
  settings take effect at the idle session boundary, and older sessions can
  resume after summary defaults change.
- Decimal rate-limit observations can be recovered from the session journal.
  Cold schema validation runs on a blocking worker to avoid exhausting the
  nested async startup stack during model changes.
- The locked `ctutils` dependency is updated to 0.4.4, addressing
  [RUSTSEC-2026-0385](https://rustsec.org/advisories/RUSTSEC-2026-0385).

## Compatibility

- The command is `/compact`; `/compress` is not an alias.
- Omitting the summary model uses the conversation model. Omitting custom
  instructions uses Smith's built-in summary instructions.
- Idle compaction defaults to one hour. Set
  `context.cache.idle_compaction = false` to disable the idle timer.
- No user credentials or personal configuration are included in the release.
- Agent Runtime remains pinned to
  `bba8996c213f2f65287d84befc1c7dc6ced3241a`.
